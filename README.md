# 动火作业前隔离确认台（油站巡检清单改造）

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

1. **创建作业票**：选择区域、动火设备（油罐/加油机/管线）、许可时段、监护人。
2. **一张票原则**：同一区域或同一设备，相邻或重叠的许可时段只能保留一张作业票；保存草稿与签发都会校验冲突，冲突列出区域、设备、时段与原值。
3. **在用设备不能签发**：油罐、加油机或管线状态为「在用」时禁止签发；先登记停用状态（停用时间、原因、确认人），再登记隔离点并逐项确认。
4. **签发冻结**：签发瞬间冻结该版本的四项巡检读数（可燃气体、氧含量、硫化氢、一氧化碳）与隔离清单，不可再直接修改。
5. **版本与回收**：现场条件变化只能新建带原因的版本，原许可回收并标记「已作旧」；新版本隔离点重新确认、巡检读数重新检测后方可再次签发。
6. **刷新一致**：作业票、隔离点、巡检版本与冲突均持久化到浏览器 localStorage，刷新后从持久化数据重算冲突，状态保持一致。

数据默认保存在浏览器 localStorage（key：`dfwlfront-10-hotwork-isolation`），方便后续扩展接口、权限、图表或地图能力。
