# 动火作业前隔离确认台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

由「油站设备巡检清单」改造，面向加油站动火作业的作业票与隔离确认闭环，数据保存在浏览器 localStorage。

## 核心规则

1. **创建作业票**：选定作业区域（加油区 / 油罐区 / 管线区等）、动火设备（油罐、加油机、管线）、许可时段与监护人。
2. **时段互斥**：同一区域内相邻或重叠时段只能保留一张已签发作业票；创建与签发前实时拦截，冲突面板列出区域、设备、冲突时段及双方原值（票号版本、原时段、监护人、签发时间）。
3. **停用前置**：油罐、加油机或管线仍在用时禁止签发；先记录停用状态（停用时间、停用方式、记录人）。
4. **隔离确认**：逐点登记隔离点（位置、方式、上锁挂签、确认人、确认时间），缺确认人或未上锁不得签发。
5. **巡检读数**：登记可燃气体浓度、氧含量、温度、残余压力等读数，按限值自动判定，存在不合格项不得签发。
6. **签发冻结**：签发后巡检读数、隔离清单、停用记录与基础信息全部冻结，只读展示。
7. **现场条件变化**：只能回收原许可并新建带原因的版本（沿用票号、版本号 +1，复制冻结数据供重新核对），版本链可追溯。
8. **刷新一致性**：作业票、隔离点、巡检版本与冲突均由同一份持久化数据派生，刷新后保持一致。
